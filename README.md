# Дорожная карта изучения Project Management



Личная база знаний для последовательного изучения управления проектами: подходов, процессов, инструментов и практических методов.

> Статус: в процессе обучения. Материалы помогают систематизировать знания и не подтверждают профессиональную квалификацию или наличие сертификатов.

## Зачем нужен этот репозиторий

- Собрать изученные темы в одном месте.
- Объяснять профессиональные понятия своими словами.
- Сохранять полезные источники.
- Связывать теорию с практическими примерами.
- Постепенно создавать портфолио учебных кейсов.

## Структура

| Файл или папка | Назначение |
|---|---|
| `ROADMAP.md` | Карта обучения из 16 этапов |
| `PROGRESS.md` | Отслеживание прогресса |
| `TEMPLATE.md` | Шаблон оформления каждой темы |
| `01-foundations/` — `16-certifications/` | Материалы по этапам |
| `case-studies/` | Практические учебные кейсы |
| `templates/` | Рабочие шаблоны и чек-листы |

## Как работать с репозиторием

1. Выбери тему в `ROADMAP.md`.
2. Создай или открой соответствующий Markdown-файл.
3. Изучи тему по нескольким надёжным источникам.
4. Заполни файл по шаблону `TEMPLATE.md`.
5. Добавь пример применения и вопросы для самопроверки.
6. Обнови `PROGRESS.md`.

## Принцип ведения базы

Не копируй большие фрагменты источников. Пересказывай материал своими словами, добавляй ссылки и отделяй подтверждённые факты от собственных выводов.

**Язык:** объяснения — на русском, международные профессиональные термины — на английском в скобках при первом упоминании.
